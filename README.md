# 🍲 Recipes Webpage

A clean, responsive, and user-friendly web page designed to showcase delicious recipes with easy-to-follow instructions, ingredient lists, and cooking steps.

🔗 **[Live Demo](https://ojasvini07.github.io/Recipes_webpage/)**

---

## ✨ Features

* **Responsive Design:** Fits seamlessly across mobile, tablet, and desktop screens.
* **Semantic HTML5:** Built using modern HTML standards for clear structure and accessibility.
* **Styled UI:** Customized CSS layout, typography, and image styling for a clean presentation.
* **Structured Content:** Organizes preparation times, ingredients, and step-by-step instructions clearly.

---

## 🛠️ Tech Stack

* **HTML5** – Page structure and content markup
* **CSS3** – Custom styling, layout, and responsiveness
* **GitHub Pages** – Deployment and hosting
