# 🍲 Recipes Webpage

A clean, responsive, and user-friendly web application designed to showcase delicious recipes with easy-to-follow instructions, ingredient lists, and cooking steps.

---

## ✨ Features

* **Responsive Design:** Fits seamlessly across mobile, tablet, and desktop screens with a balanced card grid layout.
* **Semantic HTML5:** Built using modern HTML standards for clear structure, better SEO, and web accessibility.
* **Styled UI:** Custom CSS layout, typography, smooth hover effects, and uniform image cards.
* **Structured Content:** Organizes ingredients, detailed step-by-step procedures, and recipe previews clearly.

---

## 🍽️ Featured Dishes

* 🥣 **Poha** – Traditional, low-calorie Indian breakfast dish made with flattened rice and spices.
* 🥙 **Dabeli** – Popular street food snack originating from Kutch, filled with spicy potatoes and chutneys.
* 🍕 **Pizza** – Italian classic baked with savory sauce, fresh toppings, and melted cheese.
* 🥘 **Pav Bhaji** – Iconic street food dish with spicy mashed vegetable curry served with soft buttered buns.
* 🥞 **Masala Dosa** – Crispy South Indian fermented crepe filled with savory spiced potato masala.
* 🍝 **Creamy Pasta** – Velvety white sauce penne pasta tossed with garlic, herbs, and bell peppers.
